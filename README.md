# Are we related?

Lesson slides for the Year 9 Science unit *Are we related?* (MYP 3), Diocesan School for Girls.

Live at **https://interactives.diocesan.school.nz/are-we-related/**

- `index.html`: unit page linking every lesson
- `L01.html` to `L14.html`: one deck per lesson
- `assets/deck.css`, `assets/deck.js`: shared slide engine (arrows or click to advance, **R** for reading mode, **F** for full screen)
- `img/`: photos from Wikimedia Commons; each slide credits its source and licence, and `img/credits.json` lists them all

Plain HTML, no build step. Edit a lesson file and push to `main`.
